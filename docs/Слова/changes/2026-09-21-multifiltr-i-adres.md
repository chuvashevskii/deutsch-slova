# Мульти-фильтр, страницы и состояние в адресе

> **Дата:** 2026-09-21 · **Тип:** функционал · **Статус:** реализовано
> **Раздел:** [Слова](../Слова.md)

## 1. Что было

Семнадцать кнопок в четыре ряда, из которых выбиралась ровно одна: часть
речи, либо род, либо прогресс. Совместить «существительные» и «die» было
нельзя. Страница рисовала всю колоду разом — на две тысячи слов это две
тысячи строк в DOM.

## 2. Что стало

### 2.1. Селект вместо кнопок

Части речи и род переехали в выпадающий список с флажками. У каждого пункта
подписано, сколько таких слов в колоде.

Артикли вложены под «существительными» с отступом и цветом рода: род есть
только у существительного, поэтому он не отдельная группа, а ветка.

| Действие | Что происходит |
|---|---|
| выбрать артикль | «существительные» включается сам |
| снять «существительные» | артикли снимаются вместе с ним |

### 2.2. Кнопками остались прогресс

**новые**, **учу**, **знаю** — как было, но теперь переключаются независимо
друг от друга.

### 2.3. Сброс

Кнопка «Сбросить» снимает все условия и поиск, гаснет когда снимать нечего.

### 2.4. Страницы

По 50 строк, листалка снизу, номер страницы в счётчике над списком.

### 2.5. Состояние в адресе

```
/words?pos=noun,verb&genus=f&status=new&q=haus&page=3
```

| Параметр | Значение |
|---|---|
| `pos` | части речи через запятую |
| `genus` | `m`, `f`, `n` через запятую |
| `status` | `new`, `learning`, `known` через запятую |
| `q` | строка поиска |
| `page` | номер страницы, с единицы |

Значения по умолчанию не пишутся. Любое изменение условий возвращает на
первую страницу. Адрес меняется через `replace`, чтобы не засорять историю
браузера на каждое нажатие.

## 3. Правила отбора

Внутри группы — «или», между группами — «и». Род отсекает только
существительные: «сущ.: der, das» вместе с «глаголы» дают мужские и средние
существительные **и всех** глаголов, а не пустой список.

## 4. Проверки

Разбор адреса и отбор вынесены в `wordsFilter.ts`, одиннадцать тестов:
запись и чтение адреса туда-обратно, мусор в параметрах (`genus=q`,
`page=-5`), номер страницы за пределами найденного, «или» внутри группы,
«и» между группами, род только для существительных.

Вживую проверено на 120 временных строках: `?pos=noun&genus=m` даёт
«4 из 120» и переживает перезагрузку, `?page=3` открывает последнюю
страницу с 20 строками, `page=99` прижимается к последней, «Сбросить»
очищает адрес полностью.
