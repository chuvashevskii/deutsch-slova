# Черновые карточки

Колода собрана из готовых карточек Anki — 1462 слова с разобранными
формами, правилами, ударениями и озвучкой. Частотный список, по которому
считается ранг, содержит 4500 слов, и сплошного покрытия у нас нет:
**в диапазоне 1–2000 закрыто 888 рангов, свободно 1112**.

Закрыть их можно только одним способом — собрать карточки по списку.
Но список даёт слово, ранг и короткий перевод, а карточка требует ещё
восемь обязательных полей, которых в нём нет. Всё остальное выводится:
частично из самого написания, частично рассуждением.

## Почему черновик обязан себя называть

Разбор, выведенный автоматически, и разбор, сделанный человеком, на
обороте карточки выглядят одинаково. Если не сказать, какой перед вами,
получится то же, от чего лечились экраны загрузки: приложение уверенно
сообщает о том, чего не знает.

Поэтому у слова есть отметка `confirmed_at`. Пока её нет:

| Где | Что происходит |
|---|---|
| Список слов | строка помечена «черновик», есть отдельный отбор |
| Оборот карточки | предупреждение с указанием, где ошибка вероятнее всего |
| «Учить» | **не попадает**, пока человек не включит в настройках |
| Состав колоды | не считается, пока не включён — иначе «0 / 2574» обещало бы карточки, которых не увидишь |

## Где я ненадёжен

Предупреждение называет два поля не для проформы. Перевод, род,
множественное и правило образования выводятся по написанию и проверяемым
правилам. **Произношение и формы неправильных глаголов — нет**, а в первой
тысяче как раз их скопление. Сверять надо прежде всего их; сказать
«проверьте всё» значит не сказать ничего.

## Согласование

Снять отметку черновика может только администратор — это и означает
«я проверил, карточка не хуже остальных». Защита двойная:

1. **Политика**: `update` на `words` разрешён только администратору.
2. **Сторож**: даже администратору через приложение разрешено менять
   единственное поле — саму отметку. Словарь заливается скриптом,
   и правка его через клиент была бы дырой. Заливка идёт служебным
   ключом, без пользователя в токене, и сторож её пропускает.

Отдельной правки полей в приложении нет. Нашли ошибку — «Что-то не так»
прямо на карточке: обращение уходит в [общий список](../Общие-списки/Общие-списки.md),
исходные данные правятся, партия заливается заново. Повторная заливка
**никогда не трогает сверенные строки**: согласование — решение человека,
и отменять его молча нельзя.

## Как устроена заливка

Партии лежат в `data/drafts/` обычным JSON: одна карточка — один объект,
поля те же, что в таблице. Чего в объекте нет, подставляется из шаблона
внутри скрипта — теми же пустыми значениями, что стоят у карточек
из колоды.

```bash
node scripts/import-drafts.mjs data/drafts/0001-0112.json
```

Идентификатор строится из ранга: `list-0042`. У карточек из Anki
идентификатор — номер заметки, числовая строка, так что столкнуться
они не могут, а происхождение видно прямо в базе.

## Проверка партий

Карточки для черновиков пишу я, и ошибиться в одном поле из сорока
легко: первая партия ушла без ударений и без правил рода, хотя в колоде
они заполнены у 85% и 79% карточек. На глаз такое не ловится — карточка
выглядит целой, просто чего-то в ней нет.

`scripts/drafts.test.mjs` проверяет файлы партий по конвенциям колоды:

| Что проверяется | Правило |
|---|---|
| часть речи, статус правила, род | из допустимых значений |
| заголовок, перевод, транскрипции | заполнены; перевод с заглавной |
| IPA | в косых чертах |
| примеры | ровно два, и переводов столько же |
| существительное | род; Singular с артиклем, Plural с `die` |
| ударение | отмечено у многосложных, номер не выходит за число гласных рядов |
| род правила | только у слова, у которого род есть |
| подписи форм | их столько же, сколько форм |
| ранги | не повторяются |

Проверка идёт по файлам, а не по базе: файл — источник, база лишь его
отражение.

**Чего она не ловит.** Правильность IPA, перевода и примеров машина
не проверит. Не проверит и то, применимо ли к слову правило рода:
`der Tag` подпадает под «дни, месяцы, времена года», а `die Zeit`
ни подо что — и то и другое законно. Это остаётся на сверку человеком,
ради которой черновики и заведены.

## Озвучки у черновиков нет

Сознательно. Записи в колоде живые, а черновикам можно только
синтезировать — разница слышна. Пока карточки не сверены, добавлять
к ним звук рано: часть разбора ещё изменится.
