# Проверки

Чем проверяется работа, кроме тестов. Тесты (`npm test`) проверяют разбор
и отбор на клиенте; всё, что живёт в базе, до них не достаёт — а именно
там ошибка бывает самой тихой.

## Полный прогон перед заливкой

```bash
npm test && npm run lint && npm run typecheck && npm run check:deck && npm run check:contract
```

## Что чем покрыто

| Проверка | Что смотрит |
|---|---|
| `npm test` | разбор, отбор, экраны — с подменёнными запросами |
| `npm run lint` · `typecheck` | стиль и типы |
| `npm run check:deck` | содержимое колоды: 12 проверок — 7 блокирующих, 5 отчётных |
| `npm run check:contract` | форма ответов базы против того, что ждут экраны |
| `scripts/check-queue.sql` | из чего собирается очередь «Учить» |
| `scripts/check-word-edit.sql` | правка и удаление карточки, и все их отказы |
| `scripts/check-known.sql` | отметка «знаю»: посев, возврат по сроку, снятие |

## Сценарии на живой базе

Три файла `.sql` — не тесты в обычном смысле, а сценарии: каждый строит
свой мирок внутри транзакции и **откатывает его целиком**. В колоде
после прогона не остаётся ничего.

```bash
psql "postgresql://postgres:postgres@127.0.0.1:54422/postgres" -f scripts/check-queue.sql
psql "postgresql://postgres:postgres@127.0.0.1:54422/postgres" -f scripts/check-word-edit.sql
psql "postgresql://postgres:postgres@127.0.0.1:54422/postgres" -f scripts/check-known.sql
```

Каждый печатает таблицу «случай / ждали / получили / ок?» и строку итога.
**Все «ок?» должны быть `t`.**

Почему они вообще есть: очередь однажды сломалась молча — стала отдавать
плоское слово вместо `{word, card}`, и экран показывал «на сегодня всё»
при тридцати словах. Ни один тест этого не заметил, потому что тесты
проверяли разбор, а стык «функция отдаёт — экран читает» держался
на памяти.

### Как в них проверяется время

Прямо: срок карточки сдвигается назад, и «через три месяца» наступает
внутри транзакции. У `check-known.sql` так проверяется главное — что
отмеченное «знаю» слово **возвращается**, а не исчезает.

Двигать надо **обе** даты, `due` и `last_review`. Сдвинув только первую,
получите заниженный интервал: планировщик решит, что ответили сразу
после посева, и прирост стабильности будет маленьким. На этом уже
[спотыкались](../Словарь/changes/2026-09-25-zhivoy-progon.md).

## Чего ни одна из них не видит

**Приложение целиком.** Экранные тесты подменяют все запросы заглушками,
так что неверное имя RPC или не тот аргумент прошли бы мимо. Флоу
карточек прогнан в браузере руками — [что нашлось](../Словарь/changes/2026-09-25-zhivoy-progon.md),
— но повторяемым это пока не сделано.
