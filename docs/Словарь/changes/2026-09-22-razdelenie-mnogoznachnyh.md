# Разделение многозначных карточек

> **Дата:** 2026-09-22 · **Тип:** содержимое словаря · **Статус:** реализовано
> **Раздел:** [Словарь](../Словарь.md)

## 1. Правило отбора решили примеры, а не перевод

Справочник говорит: слэш — оттенки одного значения, а разные значения —
разные карточки. Но «разные значения» на глаз определяется плохо:
`Baby` «Малыш / младенец» и `Decke` «Потолок / одеяло» в переводе
выглядят одинаково — два слова через слэш.

Различает их проверяемый признак: **подкреплены ли оба значения
примерами**. У `Decke` один пример про лампу на потолке, другой
про одеяло — два значения, каждое живёт. У `Box` «Колонка / коробка»
оба примера про аудиоколонку — коробки на карточке нет вовсе.

Из 530 карточек со слэшем это дало 13 разделений и 8 чисток перевода.

## 2. Восемь карточек обещали то, чему не учат

| слово | было | оба примера про |
|---|---|---|
| `behalten` | Оставлять себе / запоминать | «оставить себе» |
| `Box` | Колонка / коробка | аудиоколонку |
| `Geschichte` | История / рассказ | историю |
| `Glück` | Удача / счастье | удачу |
| `Hals` | Шея / горло | боль в горле |
| `Kreis` | Круг / округ | круг людей |
| `träumen` | Мечтать / видеть сон | мечту |
| `wiegen` | Весить / взвешивать | собственный вес |

Делить тут нечего: второе значение существовало только в переводе.
Оно снято.

## 3. Тринадцать разделено

`abnehmen`, `behandeln`, `Boden`, `Decke`, `einstellen`, `Knopf`, `los`,
`lösen`, `Ofen`, `riechen`, `streichen`, `studieren`, `zunehmen`.

Новая карточка: `id` + `_b`, наследует формы, произношение, ударения,
род, приставку и ранг — слово-то одно. Расходятся перевод, `rektion`
и примеры.

**Примеры пришлось дописывать.** У исходной карточки их было ровно два,
по одному на значение, а правило требует двух на карточку. Тринадцать
новых немецких предложений с переводами написаны здесь.

Все тринадцать рождены **черновиками**: правленую карточку колоды
владелец когда-то утверждал, а эту — нет.

## 4. Управление разошлось там, где оно и правда разное

| слово | значение | управление |
|---|---|---|
| `riechen` | Нюхать | `etw. (Akk.)` |
| `riechen` | Пахнуть | `nach etw. (Dat.)` |
| `studieren` | Изучать | `etw. (Akk.)` |
| `studieren` | Учиться в вузе | `an etw. (Dat.)` |
| `abnehmen` | Худеть | `ohne Objekt` |
| `abnehmen` | Снимать | `etwas (Akk.)` |

Это и есть признак из справочника: «за одним глаголом стоят разные
значения — с разным управлением и разными примерами».

## 5. Что осталось со слэшем и почему

Около 500 карточек. Это законные случаи двух родов:

- **пара «прилагательное / наречие»**: `aktiv` «Активный / активно» —
  одно немецкое слово в двух русских формах, справочник требует писать
  их через слэш;
- **оттенки одного значения**: `sparen` «Копить / откладывать»,
  `Baby` «Малыш / младенец».

Отдельно `Heizung` «Отопление / батарея»: это единственное
и множественное число одного слова, и перевод честно показывает оба.
