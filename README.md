# Deutsch für jeden Tag

Тренажёр немецких слов по частотному рангу. В колоде 1462 слова
с озвучкой — они заливаются из личной коллекции Anki.

## Что готово

- **Разбор форм на обороте карточки**: цвет рода, подчёркнутый суффикс,
  окончание множественного числа, чередование с умлаутом, ударение,
  IPA и русская транскрипция, плашка правила образования формы.
- **Управление глагола** чипсами с раскраской падежей.
- **Озвучка каждой формы** отдельной кнопкой: у существительного
  единственное и множественное, у глагола инфинитив и всё спряжение,
  у прилагательного степени сравнения.
- **Интервальные повторения на FSRS**: одна карточка — одна оценка, промах
  в любой форме отправляет слово заново.
- **Список слов** с фильтром по части речи и роду, отметками прогресса,
  поиском и постраничным выводом. Условия и номер страницы живут в адресе:
  список переживает перезагрузку и передаётся ссылкой.
- **Отметки на словах**: «учить сегодня» двигает слово в начало очереди
  мимо дневного лимита, «знаю» убирает его из очереди, «сбросить
  прогресс» возвращает слово в новые, не трогая журнал ответов.
- **Настройки ввода**: что печатать с клавиатуры, задаётся по группам
  форм — по умолчанию карточка не спрашивает ничего, кроме артикля.
  Там же дневной лимит новых слов и псевдоним.
- **Статистика**: путь по частям частотного списка, состав колоды,
  прогноз на две недели, активность, матрица путаницы в роде, ошибки
  в разрезе правила. Считается агрегатами в базе — журнал повторений
  на клиент не выгружается.
- **Общие списки**: обращения по карточкам со снимком слова и бэклог
  слов на будущее. Читают все вошедшие, пишет каждый своё, разбирает
  администратор.
- **Вход** через Google, прогресс закрыт политиками Row Level Security.

Два правила проходят через всё приложение: измеренное не смешивается
с объявленным (точность считается только по проверенным ответам,
«знаю сам» не сливается с заслуженным «знаю») и экран не выдаёт незнание
за знание — сбой загрузки называется сбоем, а не пустыми данными.

Логика разбора форм лежит в `src/shared/lib/german.ts` и покрыта тестами —
она не зависит от того, чем наполнен словарь.

## Словарь

Источник правды — коллекция Anki, а не репозиторий: словарь и озвучка
личные, а репозиторий публичный. В базу их приносит повторяемый скрипт.

```bash
npm run import:anki
```

Сейчас это 1462 слова: 789 существительных, 365 глаголов, 180
прилагательных, 99 наречий и 29 служебных. У 1157 есть место в частотном
списке 1–4500; у остальных ранга нет — их в списке попросту не оказалось.
Озвучка есть у 1450 слов, 4178 файлов.

Подробности — в [Словаре](./docs/Словарь/Словарь.md).

## Запуск

```bash
npm install
npm run db:start                    # локальный Supabase в Docker
cp .env.example .env                # подставить ANON_KEY из вывода supabase status
npm run import:anki                 # словарь и озвучка из запущенного Anki
npm run dev
```

Вход через Google. Чтобы он заработал локально, нужен OAuth-клиент в Google
Cloud Console (тип «Web application») с redirect URI
`http://127.0.0.1:54421/auth/v1/callback`; его `client_id` и `secret`
прописываются в `.env`.

## Посмотреть с телефона

```bash
npm run dev:lan
```

Открыть `http://<адрес-мака>:5173` с телефона в той же сети. Адрес Supabase
подставляется из адресной строки, отдельной настройки не нужно.

Google вход по сети не сработает: Google не принимает приватные адреса вида
`192.168.x.x` как redirect URI, а локальный Supabase выдаёт себя за
`127.0.0.1` — с телефона этот адрес указывает на сам телефон. Поэтому при
открытии по сетевому адресу кнопка Google не показывается вовсе, а вместо
неё стоит блок «Локальный вход» — почта и пароль, только в дев-режиме.
Заведите одноразовый аккаунт кнопкой «Завести аккаунт»: подтверждение почты
в локальной конфигурации выключено, сессия выдаётся сразу.
