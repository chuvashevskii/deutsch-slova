# Карантин для карточек, собранных по списку

> **Дата:** 2026-09-22 · **Тип:** данные, схема, интерфейс · **Статус:** реализовано
> **Раздел:** [Черновики](../Черновики.md)

## 1. Сначала проверили то, что уже есть

Перед тем как добавлять слова, разобрали состояние колоды — и две мои
прежние оценки оказались неверными.

**«83 лишних карточки из-за задвоенных рангов» — неверно.** Задвоенных
рангов 95, но совпадений и по слову, и по переводу — **ноль**. 44 ранга
это два значения одного слова (`finden` — находить / считать), 57 —
разные слова, которым частотный список дал один номер (`lang` / `lange`,
`spät` / `später`, `verstehen` / `sich verstehen`). Сливать нечего;
предложение «разобрать дубли» уничтожило бы содержимое колоды.

**«Проставить рангу 1294 слово `fernsehen`» — неверно.** Под 1294 в списке
стоит `das Fernsehen` (телевидение, существительное), а в колоде — глагол
`fernsehen` (смотреть телевизор). Разные слова. Остальные шесть похожих
совпадений тоже ложные: 151 занято `Mal` против частицы `mal`, 1595 —
прилагательное `orange` против `die Orange`, 3054 — `das Verfahren`
против `sich verfahren`.

Итог проверки: **чинить нечего**, импорт отработал верно, 1112 свободных
рангов остаются 1112.

## 2. Отметка о сверке

```sql
alter table public.words add column confirmed_at timestamptz;
update public.words set confirmed_at = now();
```

Всё, что пришло из готовой колоды, сверено по определению: это образец,
с которым сравниваются черновики. Новые строки заливаются с `null`.

Право снимать отметку — у администратора, и только на неё:

| Уровень | Что делает |
|---|---|
| Политика `update` | пускает только администратора |
| Сторож `guard_word_update` | не даёт изменить ничего, кроме `confirmed_at` |
| Исключение | `auth.uid() is null` — заливка служебным ключом, иначе повторный импорт стал бы невозможен |

Проверено на живой базе: обычный пользователь получает `UPDATE 0`
(отсекает политика), администратор при попытке поменять перевод получает
`Через приложение у слова меняется только отметка о сверке`, отметку
снимает и возвращает свободно.

## 3. Настройка «давать черновики в Учить»

`user_settings.include_drafts`, по умолчанию `false`. Её читают очередь
и сводка состава колоды — обе по одному правилу, иначе «выучено 0 / 2574»
обещало бы карточки, которых человек не увидит.

Проверено запросом к `learn_queue` за одного и того же пользователя:

| Настройка | Черновиков в очереди из 30 |
|---|---|
| выключена | **0** |
| включена | **4** |

## 4. Что видно в интерфейсе

Список слов показывает черновики **всегда** — иначе их нечем сверять.
Пометка стоит на строке, до раскрытия карточки; отбор «черновики N»
стоит отдельно от состояний знания, потому что черновик бывает и новым,
и уже выученным.

На обороте — предупреждение, которое называет два поля: произношение
и формы. Это не вежливость, а указание, куда смотреть: остальное
выводится по проверяемым правилам, а эти два — хуже всего.

## 5. Первая партия

Двадцать слов, ранги 12–112. Партия намеренно маленькая: формат карточки
надо было показать до того, как он размножится на тысячу.

Что заполняется и откуда:

| Поле | Источник |
|---|---|
| `head`, `rank`, `translation` | частотный список |
| `genus`, `plural`, `plural_ending` | подсказка списка «der Tag, -e» плюс правила |
| `ipa`, `pronunciation_ru` | вывод по написанию — **слабое место** |
| `rule_status`, `rule_label` | правила образования, словарь значений взят из колоды |
| `examples_de`, `examples_ru` | составлены под значение слова |
| `definition`, `frequency`, `corpus_share` | пусто и нули — как у всех карточек колоды |
| озвучка | не заполняется до согласования |

Пометки списка вроде «andere (r, s)» и «jeder, jede, jedes» приведены
к одной словарной форме: в заголовке `andere` и `jeder`, склонение видно
из примеров.
