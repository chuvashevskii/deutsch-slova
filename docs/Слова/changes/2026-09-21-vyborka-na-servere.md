# Отбор и страница переехали в базу

> **Дата:** 2026-09-21 · **Тип:** архитектура · **Статус:** реализовано
> **Раздел:** [Слова](../Слова.md)

## 1. Что было не так

Список тянул всю колоду со всеми полями и фильтровал в памяти. На двух
тысячах слов это 2,2 МБ за сеанс, причём строке нужно восемь полей из
тридцати восьми — пять шестых трафика уходило впустую. Постраничность
экономила только отрисовку.

Хуже того, шапка приложения тоже звала весь словарь ради двух чисел,
а висит она на каждом экране — значит словарь грузился всегда.

## 2. Что стало

Четыре функции в базе, все с правами вызывающего, поэтому политики RLS
продолжают действовать:

| Функция | Что возвращает |
|---|---|
| `words_page` | страницу списка, статус слова и общее число найденного |
| `words_facets` | сколько слов каждой части речи и каждого рода |
| `progress_summary` | состав колоды и покрытие текста для текущего пользователя |
| `word_status` | статус одного слова, общий для остальных функций |

Плюс `like_escape` — строка поиска как безопасный шаблон.

Клиент:

- список зовёт `words_page` с условиями из адреса;
- счётчики в фильтре — `words_facets`, считаются по всей колоде, чтобы
  цифра рядом с пунктом не прыгала от уже выбранного;
- шапка — `progress_summary` вместо словаря;
- полная карточка — отдельный запрос по `id`, когда строку развернули.

## 3. Сколько стало весить

| | Было | Стало |
|---|---|---|
| открытие вкладки | 2 243 КБ, 3 запроса | **9,9 КБ**, 3 запроса |
| зависит от размера словаря | да | нет |

Из них страница на 50 строк — 9,7 КБ, счётчики 82 байта, сводка 74 байта.

## 4. Отбор не изменился

Правила те же, просто считает их теперь Postgres. Внутри группы «или»,
между группами «и», род отсекает только существительные. Проверено на
двухстах строках:

| Условие | Найдено |
|---|---|
| сущ. | 66 |
| сущ. + глаголы | 133 |
| сущ.: die | 22 |
| сущ.: der + глаголы | 89 — 67 глаголов и 22 мужских существительных |
| знаю | 5 |
| поиск `%` | 0 — шаблонные знаки экранируются |
| поиск `  42  ` | по точному рангу, пробелы обрезаются |

## 5. Что сломалось бы без этого

Ответ на карточке меняет статус слова и сводку прогресса, а считает их
теперь база. Поэтому после записи ответа сбрасывается кэш обеих выборок —
иначе отметки в списке и счётчик в шапке застыли бы.

## 6. Чего это не коснулось

Экраны «Учить» и «Статистика» на этом шаге ещё брали словарь целиком —
их перевели следом, в
[Статистика · изменения](../../Статистика/changes/2026-09-21-agregaty-v-baze.md).
Служебная страница образцов, которая тоже брала словарь целиком, позже
удалена как черновая.
