# Живой прогон флоу карточек

> **Дата:** 2026-09-25 · **Тип:** проверка · **Статус:** пройден
> **Раздел:** [Словарь](../Словарь.md)

## 1. Вопрос

«Ты флоу работы с карточками всё протестировал? Работает как надо?»

Честный ответ был «нет». Проверены два слоя из трёх:

| Слой | Как проверен |
|---|---|
| SQL — функции, очередь, отказы | сценариями на живой базе: 18 + 13 + 7 случаев |
| модели и экраны | 1424 теста |
| **приложение целиком, в браузере** | **никак** |

Третье — настоящая дыра. Экранные тесты подменяют все запросы
заглушками, так что неверное имя RPC или не тот аргумент прошли бы
мимо них незамеченными.

## 2. Что прошли

Локальный стенд, настоящая база, сессия временного администратора
(заведён через админский API, удалён после прогона).

| Шаг | Результат |
|---|---|
| завести карточку формой | `my-0001`, экран назвал номер |
| отбор «заведено руками» | фишка появилась, «1 из 2587» |
| раскрыть строку | «Учить сегодня», «Знаю», «Править» на месте |
| подсказка с заглавной | красный блок, кнопка мертва |
| сохранение | «Полей изменено: 2», две строки журнала с причиной `правка` |
| «Знаю» на обычном слове | посеяно `state=2, scheduled=90, stability=90, reps=1` |
| очередь | `sein` (№1) ушёл, первым стал №2 |
| сдвинуть срок на «через 90 дней» | **`sein` вернулся первым** |
| ответить «Хорошо» | интервал 223 дня, отметка снялась триггером |
| снять отметку у другого слова | посеянная карточка удалена, заработанная цела |
| удалить свою карточку | ушла вместе с журналом, колода снова 2586 |

После прогона в базе: ноль пользователей, ноль карточек, ноль отметок,
2586 слов (1124 черновика) — ровно как было.

## 3. Что поймал прогон и не поймали тесты

### Плашка черновика врала своим карточкам

На карточке, написанной руками, стояло: «собрана по частотному списку,
а не взята из готовой колоды». Её никто не выводил — её написал человек.

Исправлено: плашка различает происхождение по номеру. Добавлен тест,
который упадёт, если своей карточке снова пообещают частотный список.

### Проверка столкновений действительно ходит в базу

Смена перевода на «Уверенность» заперла сохранение: так же переводится
`Sicherheit`, у которой нет ни пометы, ни подсказки. Это не поломка,
а работа правила — и заодно доказательство, что запрос соседей уходит
на сервер, а карточка не считает соседкой саму себя.

### Собственный замер интервалов был неполон

Сдвинув только срок `due`, получили «Хорошо → 3 месяца» вместо
расчётных 7,5. Причина не в функции: FSRS смотрит на `last_review`,
а он остался сегодняшним — для планировщика это «ответил сразу после
посева». Сдвинули и его — стало **8 месяцев**, сходится с расчётом.

Вывод на будущее: проверяя срок, двигать надо обе даты.

## 4. Попутная оплошность

Файл нового теста назвали `draftNotice.test.tsx` при существующем
`DraftNotice.test.tsx`. На macOS файловая система нечувствительна
к регистру, так что это один и тот же файл: сначала дописали в него
поверх, потом удалили. Восстановлен из гита, случай дописан
в существующий.
