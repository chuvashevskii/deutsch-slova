# Диапазон 1–2000 закрыт

> **Дата:** 2026-09-22 · **Тип:** данные · **Статус:** реализовано
> **Раздел:** [Черновики](../Черновики.md)

## 1. Что было и что стало

| | Было | Стало |
|---|---|---|
| слов в колоде | 1462 | 2572 |
| закрыто рангов 1–2000 | 888 | **1995** |
| свободных номеров | 1112 | 5 (намеренно) |

Двадцать три партии, 1110 карточек. Каждая партия прошла проверку,
залита и закоммичена отдельно.

## 2. Что в каждой карточке

| Поле | Заполнено |
|---|---|
| два примера с переводом | 1110 из 1110 |
| IPA и русская транскрипция | 1110 из 1110 |
| род и множественное у существительных | 436 из 436 |
| правило рода у существительных | 300 из 436 |
| пять форм и управление у глаголов | 337 из 337 |

Правила рода брались не наугад, а из словаря правил самой колоды —
37 правил с указанием, какой род каждое предсказывает. Двадцать два
существительных помечены **исключениями**: `die Nacht` против правила
«дни и месяцы», `der Euro` против «-o», `das Feuer` и `das Wunder`
против «-er», `die Gefahr` и `die Gegend` против «Приставки Ge-».

## 3. Три случая с двумя родами

`der/die Deutsche`, `der/die Fremde`, `der/die Erste` — решение нашлось
в самой колоде: `Bekannte`, `Erwachsene`, `Jugendliche` лежат там
парами, по карточке на род. Сделано так же — две карточки на одном
ранге, у каждой свой идентификатор.

## 4. Чего проверка не ловит

Она следит за формой: часть речи, IPA в косых чертах, два примера,
артикль у Singular, ударение в пределах числа гласных рядов,
неповторяющиеся идентификаторы. За семь партий она поймала шесть
настоящих ошибок — четыре неверных ударения, отсутствующее ударение
и ударение у аббревиатуры, в которой гласных нет вовсе.

Правильность IPA, перевода и примеров она проверить не может. Формы
неправильных глаголов — тоже. **Это и есть то, ради чего карточки
остаются черновиками.**

## 5. Что дальше

Озвучки у черновиков нет намеренно: часть разбора ещё изменится после
вашей сверки, и синтезировать звук к неутверждённому тексту рано.

В «Учить» черновики не попадают, пока не включена настройка. Согласовать
карточку может только администратор — в проде для этого нужно добавить
себя в `admins`.
