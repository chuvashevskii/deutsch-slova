# Крутилка встала на нажатую кнопку вместо её подписи

> **Дата:** 2026-09-22 · **Тип:** интерфейс, исправление · **Статус:** реализовано
> **Раздел:** [Общее правило](../../README.md), [Настройки](../../Настройки/Настройки.md)

## 1. Четыре крутилки из пяти

В «Новых словах в день» условие было такое:

```tsx
{saving === 'daily_new_limit' && settings.daily_new_limit !== limit ? <Spinner /> : null}
```

Во время запроса сохранённое значение ещё старое, поэтому «не выбрано»
верно для **всех** кнопок, включая нажатую. Нажимаешь «40» — крутятся
10, 30, 40 и 50. Выглядит как общий индикатор экрана, по которому не
понять, что именно приняли; ровно наоборот тому, ради чего он ставился.

## 2. Крутилка вращалась по орбите

Центровка была сделана трансформом:

```tsx
className="absolute left-1/2 top-1/2 -translate-x-1/2 -translate-y-1/2"
```

А `animate-spin` — это тоже `transform`, и он затирает сдвиг целиком.
Кольцо вращалось не вокруг своего центра, а вокруг угла кнопки: заметная
кривая болтанка. Теперь центрует обёртка (`absolute inset-0 flex`),
а на самой крутилке трансформа нет. Проверено замером: центр кольца
совпадает с центром кнопки на всех кадрах анимации.

## 3. Ожидание — не запрет

Кнопки гасли на 40% через `disabled:opacity-40`, потому что на время
запроса их отключают. Тёмная кнопка со светлой крутилкой превращалась
в серое пятно.

Гашение оставлено настоящему «сейчас нельзя». Запрос — это ожидание:
кнопка остаётся в своём цвете, а о недоступности говорит курсор.
Выражено это [одной функцией](../../../src/shared/ui/busyClasses.ts),
чтобы правило не пришлось вспоминать на каждой кнопке.

## 4. Что изменилось на экранах

| Экран | Кнопки |
|---|---|
| Настройки | лимит новых слов, «Сохранить» у псевдонима |
| Слова | «Учить сегодня», «Знаю», «Сбросить прогресс» |
| Обращения | «Разобрано», «Удалить» |
| Бэклог | «В бэклог», смена состояния, «Удалить» |
| Карточка | «Отправить» в обращении |
| Учить | оценки — крутилка на месте срока, подпись оценки остаётся |

Оценки — единственное исключение из правила «вместо подписи»: там
крутилка занимает место срока под названием оценки. Скрыть саму подпись
значило бы спрятать, какую из четырёх кнопок нажали.

Галочки настроек тоже не подпадают: у флажка крутилка стоит рядом
с подписью. Это строка с флажком, а не кнопка, — подменять там нечего.

## 5. Заодно

**Состояние `saving` удалено.** Какая настройка сохраняется, мутация
знает сама — это её аргументы. Отдельное состояние рядом умело
разойтись с ними: оно гасло по `onSettled`, а запрос ещё шёл.

**Проверка типов шла вхолостую.** Команда `tsc --noEmit` без указания
проекта ничего не проверяла: корневой `tsconfig.json` содержит
`"files": []` и только ссылки на проекты. Правильно — `npm run typecheck`
(или `tsc -b`, как в сборке). Синтаксическая ошибка, внесённая в этой же
работе, прошла мимо холостой команды и была поймана сборкой.
