# AGENTS.md

Инструкция для AI-агентов, работающих в этом репозитории.

## Проект

Zweitausend — тренажёр двух тысяч немецких слов по частотности.
Источник содержимого — личная колода Anki: разбор форм, управление глаголов,
транскрипция и примеры взяты оттуда. Ранг слов посчитан по открытому
частотному списку OpenSubtitles (`de_50k`, MIT).

- **Frontend:** React 19 + TypeScript + Vite
- **UI:** Tailwind CSS, токены в [DESIGN.md](./DESIGN.md)
- **Backend:** Supabase (PostgreSQL + Auth + RLS)
- **Состояние сервера:** TanStack Query
- **Повторения:** FSRS через `ts-fsrs`
- **Архитектура:** Feature-Sliced Design

## Структура `src/` (FSD)

```
src/
├── app/       # провайдеры, роутер, глобальные стили
├── pages/     # страницы: композиция виджетов и фич, роутинг
├── widgets/   # крупные самостоятельные блоки UI
├── features/  # пользовательские сценарии (вход)
├── entities/  # бизнес-сущности: word, review
└── shared/    # api-клиент, утилиты, конфиг, типы
```

Зависимости строго сверху вниз: `app → pages → widgets → features → entities →
shared`. Слой не импортирует из вышестоящих. Роутинг и синхронизация с URL —
ответственность `pages`.

## Правила написания кода

- **Не используй `void`.** Асинхронные вызовы — через `await` или явный `.catch()`.
- **Не используй однобуквенные имена переменных.** Это касается и параметров
  колбэков, и индексов, и обработчиков событий: `word`, `wordIndex`, `event`.
- **Без повествовательных комментариев.** Код объясняет себя именованием. Если
  комментарий всё же нужен как осознанное исключение, начинай с `INFO:` и
  указывай причину.
- **Без надгробий.** Не оставляй `// removed`, `// deleted` при удалении кода.
- **Чистая логика отдельно от UI.** Разбор словоформ живёт в
  `src/shared/lib/german.ts` и покрыт тестами; компоненты только рисуют.

## Правила рода существительных

Плашка правила на карточке существительного утверждает, что род слова
предсказуем. Это утверждение проверяемое, и оно должно быть верным.

- **Правило ставится, только если слово действительно подпадает под него.**
  `der Mensch` — «человек вообще», а не мужское лицо, поэтому правило
  «мужские лица и профессии» к нему неприменимо, хотя род совпадает.
  Совпадение рода само по себе не повод приписать правило.
- **Исключением слово может быть только из того правила, которое его
  покрывает.** `das Kind` не является исключением из «мужских лиц»:
  ребёнок под эту категорию не подпадает вовсе, значит и нарушать её
  не может. Такому слову ставится «правила нет».
- **Метка не переносится между омонимами.** `das Eis` «лёд» законно
  разбирается правилом «погода и осадки», `das Eis` «мороженое» — нет.
- **Суффиксное правило ставится, только если окончание — действительно
  этот суффикс.** Арбитр здесь — текст самого правила: если он говорит
  «в заимствованиях это не суффикс», то `die Medizin` под правило `-in`
  не подпадает, хотя и оканчивается на нужные буквы. Такому слову ставится
  статус «не суффикс», а не «исключение»: правило к нему не применялось.
- **Правило составного слова ставится, только если последний корень
  проверяем.** Корень должен сам быть словом колоды, и его род должен
  совпасть с родом составного. Так отсеиваются `das Gegenteil` (по
  `der Teil` вышел бы мужской) и `der Hinweis` (никакого `das Eis` там нет).
- **Сомневаешься — ставь «правила нет».** Отсутствие подсказки честно
  говорит «род запоминается». Ложная подсказка хуже отсутствующей:
  она учит несуществующей закономерности.

Суффиксные правила применяются программно и только при совпадении рода:
расхождение чаще означает ложное срабатывание по окончанию, чем настоящее
исключение. Смысловые правила автоматом не применяются никогда — только
вручную, с проверкой по значению слова.

Проверять эти утверждения нужно на всей колоде сразу, а не на отдельной
карточке: ошибка вида «правило приписано по совпадению» в одном слове
почти всегда означает такую же ошибку ещё в десятке.

## Слово карточки — то, что стоит в частотном списке

Ранг задаёт слово целиком, включая часть речи. Под рангом 1450 стоит
`russisch` «русский» — прилагательное, и карточка должна спрашивать
прилагательное, даже если в колоде Anki нашлось созвучное `das Russisch`.
Подмена созвучным словом — это карточка, которая спрашивает одно, а
переводит другое; ищутся такие расхождения сверкой регистра и артикля
списка с `pos` в базе.

У слова, которое существует только во множественном числе, рода нет:
`genus` остаётся пустым, иначе тренировка спрашивает der/die/das там,
где артикль всегда «die».

## Чем заполняют пустые поля

Выведенное значение ставится только после сверки метода с ручной разметкой
колоды Anki — она здесь единственный источник истины о том, «как правильно».
Сверка идёт по словам, где поле уже заполнено вручную, и её результат
записывается в миграцию: «634 слова, 100% совпадений, покрытие 98%».
Метод, дающий меньше, не применяется.

- **Ударение** выводится из IPA: номер гласной группы в написании. Если
  число гласных групп не сходится с числом гласных пучков в транскрипции,
  буква и звук разошлись («qu» в bequem, немая «e» в -en) — поле остаётся
  пустым. Пустое честнее неверного.
- **Ударение множественного числа не ставится.** В колоде оно проставлено
  у одного слова из 868 — `der Professor → die Professoren`, — то есть
  помечается только сдвиг ударения, а не само ударение.
- **Односложные слова знаком ударения не метятся**, включая заимствования,
  которые односложны в произношении: die Chance, das Team, das Niveau.
- **Примеры** — ровно два предложения уровня A1–A2. У существительного
  первое в единственном числе, второе во множественном.
- **Перевод примера держится слова карточки.** Слово переводится своим
  словарным соответствием, а не синонимом по смыслу: «Er unterstützt
  seinen Bruder» — «поддерживает», а не «помогает», иначе перевод прячет
  ровно то слово, которое учат. Структура немецкой фразы сохраняется.
  Грамотность русского при этом не приносится в жертву: падежи не ломаем
  и служебные обороты (`es gibt`, `man`) не калькируем. Если слово
  в прямом значении в предложение не встаёт, меняется предложение,
  а не перевод.

Прочерк «—» из Викисловаря означает «формы нет» и в базу попадать не должен:
в поле кладётся NULL. Литеральный прочерк карточка показывает как форму.

## База данных

- Миграции — `supabase/migrations/`, применяются `supabase db reset`.
- У каждой таблицы своя политика RLS. Словарь `words` читают все вошедшие,
  `cards`, `reviews` и `user_settings` видит только владелец строки.
- Типы генерируются из локальной базы: `npm run generate:types:local`.
- Локальный стек поднят на портах 544xx, чтобы не конфликтовать с другими
  проектами Supabase на той же машине.

## Настройки работы агента

**Язык.** Отвечай на русском.

**Критические правила:**

- Никогда не удаляй и не переписывай рабочие тесты без явного запроса.
- Никогда не удаляй файлы без подтверждения.
- Всегда запускай тесты после изменения кода.
- Если не уверен — спроси, не угадывай.
